# Архитектура VESTORA

В этом документе описано внутреннее устройство системы VESTORA.

## Обзор системы

VESTORA соединяет веб-интерфейс с мощностями Blender для параметрической генерации тел.

## 1. Frontend (React + Three.js)

- **Landing Page**: [Landing.tsx](src/Landing.tsx). Чистый React + Tailwind. Не требует работающего бэкенда для разработки UI.
- **Dressing Room**: [App.tsx](src/App.tsx). Интеграция с Three.js.
- **3D Viewer**: Использует React Three Fiber. Модели загружаются через `useGLTF`.

## 2. Backend (FastAPI)

- **API**: `backend/app/main.py`.
- **Процесс**: Запускает Blender как `subprocess`.
- **Конфигурация**: Путь к Blender (`BLENDER_EXECUTABLE`) может требовать ручной настройки под вашу систему.

## 3. Body Engine (Blender + MPFB2)

- **Механика**: Деформация модели через морф-таргеты (targets) MPFB.
- **Калибровка**: Итерационный алгоритм подгоняет меш под числовые значения.
- **Точность**: Система обеспечивает **высокую числовую сходимость** (ошибка < 0.1 см для внутренних алгоритмов измерения), однако это **не является доказательством полной анатомической точности** реконструкции тела конкретного человека. Измерения служат базой для визуализации и примерки.

## Статус функциональности

### ✅ Стабильно (Working)
- Рост (Height)
- Обхват груди (Chest)
- Обхват талии (Waist)
- Обхват бедер (Hips)
- Экспорт чистого GLB (без хелперов)

### 🧪 Экспериментально (Experimental)
- Ширина плеч (Shoulder Width) — исследование таргет-групп и точности деформации.

### 📅 Запланировано (Planned)
- Обхват шеи (Neck)
- Длина рук (Arm length)
- Шаговый шов (Inseam)

## Data Flow (Путь данных)

Пользователь (Measurements) → React → FastAPI → Blender (MPFB) → Итерационная калибровка → Очистка меша → GLB → Three.js Viewer.
